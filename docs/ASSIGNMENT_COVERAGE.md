# Assignment coverage and verification notes

| Requirement | Current demo implementation | Verification / boundary |
|---|---|---|
| New and used inventory browse/filter | Inventory API + React filters | Seeded stock; no full-text search engine |
| Model/variant detail pages, photos, specs, colours | Vehicle detail route and fields | React SPA routes; server-side rendering/prerendering not configured |
| City-wise on-road price breakup | `CityPrice` per vehicle/city; deterministic calculator | Lucknow/Kanpur/Varanasi seed values; never generated by AI |
| Price validity and change note | Vehicle validity date + admin note in API response | Admin-created vehicle gets 15-day default; existing records may need admin refresh |
| Certified used listings, owners, masked registration, inspection | Used metadata on vehicle model and detail page | Seeded inspection text is synthetic |
| Test drive by showroom and demo vehicle | Date/showroom/vehicle form + availability endpoint + duplicate-slot database constraint | No real showroom calendar integration |
| Service booking by workshop capacity | Service booking form + three-per-slot demo capacity rule | Count check is not a production-grade concurrent reservation lock |
| EMI calculator | Down payment/rate/tenure calculator | Indicative estimate, no lender integration |
| Trade-in request | Form + persisted trade-in request | No automated appraisal or historical trade-in integration |
| Lead inbox and status | Persisted lead inbox + status endpoint | Sales/admin roles |
| Legacy portal CSV import | Sales/admin CSV import endpoint + admin UI | Simple unquoted CSV format only |
| Auto-assignment by showroom/model | Rules for showroom and used-car category | Synthetic consultant email aliases; not real staff directory |
| Five-minute response target | Lead age/SLA indicator and simulated acknowledgement | No automatic calling/real SMS; response remains a staff action |
| Admin models, stock and city prices | Add vehicle, status update, per-vehicle/city price table | Admin role protected |
| Admin offers, banners, user roles | Content API/UI and role update UI | No approval workflow or audit history |
| Buyer and sales roles | JWT login and endpoint authorization | Used-car manager role added for restricted valuation |
| AI buyer summary and first reply | Groq when configured; fallback summary/draft otherwise | Draft-only; human review; no automatic sending |
| Used-car price band | Used-car manager/admin-only comparable sales endpoint | Seeded synthetic sale records; not real historical dealer data |
| Consent and opt-out | Consent checkbox enforced on lead/booking/service/trade-in; opt-out endpoint | Demo record-level preference, not a full DPDP compliance program |
| Hindi and English | Not fully implemented | Translation/localization is a remaining gap |
| Page load under 2.5s on 4G | Not performance-tested | Requires deployment profiling with real assets/network |
| Indexable individual vehicle pages | Distinct client routes `/cars/{id}` | SPA metadata/prerendering/SSR still required for reliable crawler indexing |

## Important honesty note
This is a fuller functional take-home demo, not a production-ready dealership system. External SMS/WhatsApp, telephony, DMS, real demo-car calendars, real workshop bay locking, production DPDP processes, Hindi localization, performance certification and SEO prerendering are not represented as completed integrations.
